# Deployment-ready ScholarBook Visa Prep demo

Do not place your OpenAI API key in any source file.

For cloud hosting:
- Environment variable: OPENAI_API_KEY
- Start command: npm start
- The app automatically reads the host-provided PORT variable.

Prototype note:
The current JSON file database is suitable for a demo only. Use a real database
before production use or before storing real athlete information.
